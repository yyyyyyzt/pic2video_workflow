# =============================================================================
# 腾讯云数智人 · 通用口型版 —— 素材生成提示词
# =============================================================================
#
# 这条提示词不是为了「好看」，而是为了让成片通过平台的素材自检。
# 腾讯的形象录制指引对模特表现有明确要求，逐条翻译成提示词就是下面这些：
#
#   平台要求「眼睛正视镜头，无大幅转头、偏头」   → 正视镜头、禁止转头
#   平台要求「脸部全程无遮挡」                   → 手不抬到面部以上
#   平台要求「画面稳定无晃动」                   → 固定三脚架机位、无运镜
#   平台要求「人脸清晰、边缘轮廓清晰」           → 禁止快速动作（会糊）
#   平台建议「说话过程可以自然小幅动作」         → 保留小幅点头和手势，别做成僵尸
#
# 开头静默闭口 1~3 秒不要写成「先吸一口气再开口」——模型会真去演吸气。
# 静默靠音频加静默头（默认 --silence 2），画面再换成角色图静止帧（默认 --still-head）。
#
# 用法：
#   python3 avatar_lab.py run --recipes <方案> --image face.jpg --audio speech.mp3 \
#       --prompt-file prompts/tencent_general_prompt.txt --profile tencent-general
#
# 以 # 开头的行会被忽略。
# =============================================================================

固定三脚架机位，镜头完全静止，无推拉摇移，无变焦。
人物端坐或站立口播，正面朝向镜头，眼睛始终正视镜头，不斜视、不看向别处。
头部只有随语气的小幅点头，不做大幅转头或偏头，面部全程完整可见、无任何遮挡。
双手自然放在身前，讲到重点时可有克制的小幅手势，手不抬到肩部以上，不遮挡面部和颈部。
表情自然亲和，随内容有细微变化，不做夸张表情，不舔嘴、不吐舌、不噘嘴。
开口前嘴唇自然闭合，不要深吸气、张嘴预备、耸肩提气，不要把静默段演成吸气动作。
躯干基本保持稳定，动作缓慢平滑，无突然位移。
光线均匀柔和，人物与背景亮度稳定，背景整洁静止、无移动物体、无其他人出镜。
画面干净，不要出现任何字幕、水印或文字。
