# =============================================================================
# 腾讯云数智人 · 通用口型版 —— 克制版（对比组）
# =============================================================================
#
# 更强调「少动、稳定」，用来和 alive 对照：是不是写了「保持稳定」才会把
# 静默段演成僵硬或吸气预备。
#
# 以 # 开头的行会被忽略。
# =============================================================================

固定三脚架机位，镜头完全静止，无推拉摇移，无变焦。
人物端坐或站立口播，正面朝向镜头，眼睛始终正视镜头，不斜视、不看向别处。
头部只有随语气的小幅点头，不做大幅转头或偏头，面部全程完整可见、无任何遮挡。
双手自然放在身前，讲到重点时可有克制的小幅手势，手不抬到肩部以上，不遮挡面部和颈部。
表情自然亲和，随内容有细微变化，不做夸张表情，不舔嘴、不吐舌、不噘嘴。
开口前嘴唇自然闭合，不要深吸气、张嘴预备、耸肩提气。
躯干基本保持稳定，动作缓慢平滑，无突然位移。
光线均匀柔和，人物与背景亮度稳定，背景整洁静止、无移动物体、无其他人出镜。
画面干净，不要出现任何字幕、水印或文字。
