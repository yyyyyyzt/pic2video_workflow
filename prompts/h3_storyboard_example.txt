# =============================================================================
# H3 分镜脚本示例（用电安全 70 秒）
# =============================================================================
# 格式：
#   ## 时长 | 段落标题        ← 时长可省略（省略时用 --prefer-duration）
#   这一段的提示词，可写多行
#
# 以单个 # 开头的行是注释，会被忽略。
#
# 写作要点（和可灵数字人的提示词写法不同）：
#   1. H3 会自己生成声音。想让人物说话，就把台词直接写进提示词，
#      例如：角色说话：「各位朋友，大家好」。台词长度要和段时长匹配，
#      否则会念不完或留白（中文口播约每秒 4~5 字）。
#   2. 每段都要重复描述人物外观与场景，否则段与段之间会漂。
#   3. 想固定机位就每段都写「固定机位」，H3 默认会给运镜。
#   4. 段与段的画面要能接上：上一段结束的姿态 = 下一段开始的姿态。
#
# 用法：
#   python3 minimax_h3.py plan  --storyboard prompts/h3_storyboard_example.txt
#   python3 minimax_h3.py chain --storyboard prompts/h3_storyboard_example.txt \
#       --image face.jpg --dry-run
# =============================================================================

## 14s | 开场问候
固定机位，中景。纯白影棚背景。一位年轻女性讲解员，白衬衫、藏青色马甲、蓝白条纹领结、盘发，
双手自然交握于小腹前，端庄站立，面向镜头浅笑。
角色说话：「各位朋友，大家好！今天我们聊一个和每个家庭都相关的话题——家庭安全用电。」
语气亲切自信，只有轻微点头与自然微表情，身体不做大幅移动。

## 14s | 指出隐患
固定机位，中景。同一位白衬衫藏青马甲、蓝白领结、盘发的女性讲解员，站姿与上一段结尾一致，
双手仍交握于身前。纯白影棚背景。
角色说话：「很多家庭火灾，根源就在一个老化的插座，或者一个超载的插线板上。」
神情转为关切，眉头轻微收紧，目光专注看向镜头。

## 14s | 强调风险
固定机位，中景。同一位白衬衫藏青马甲、蓝白领结、盘发的女性讲解员，纯白影棚背景，
站姿延续上一段，双手交握身前。
角色说话：「还有，用湿手去触碰电源开关，非常危险。这些看似不起眼的疏忽，可能引发严重后果。」
语气加重，轻微摇头表示不可取，随后恢复平稳。

## 14s | 三个要点
固定机位，中景。同一位白衬衫藏青马甲、蓝白领结、盘发的女性讲解员，纯白影棚背景。
角色说话：「记住三点。第一，人走断电。第二，保持干燥，手不干绝不碰电。第三，定期检查线路。」
语气笃定专业，讲到每一点时轻微点头强调，手部保持交握不挥动。

## 14s | 结语呼吁
固定机位，中景。同一位白衬衫藏青马甲、蓝白领结、盘发的女性讲解员，纯白影棚背景。
角色说话：「安全无小事，细节保平安。让我们一起守护家人的温馨生活。感谢观看！」
神态松弛温和，嘴角笑意加深，以微微点头收尾，最后保持静止姿态。
