# =============================================================================
# 怎么写数字人提示词（先读这个）
# =============================================================================
#
# 数字人接口 = 参考图 + 音频 + 提示词。三者职责要分清：
#
#   参考图  → 管长相、发型、穿搭、站姿、构图（已经拍进画面的，就别在提示词里重复太多）
#   音频    → 管说什么、时长、口型、语速（台词写进提示词几乎没用，口型跟着音频走）
#   提示词  → 只管「怎么演」：镜头、动作幅度、情绪、禁止事项
#
# 下面这些写进提示词通常无效或干扰，不要写：
#   - 时长 / 24fps / 4K（接口不认，成片规格由模型和音频决定）
#   - 完整台词 / 独白原文（那是音频的事）
#   - 精确到秒的分镜脚本（0–5s、5–20s……模型跟不准，长视频尤其如此）
#   - 「全程静默」「无配乐」（静默靠音频前几秒留白，不是提示词）
#
# 真正有用的：
#   - 固定机位 / 禁止大幅度手势 / 双手保持交握
#   - 情绪曲线（开场→关切→笃定→温和）
#   - 画面限制（白背景、无字幕）
#
# 用法：
#   python3 kling_avatar.py --image face.jpg --audio speech.mp3 \
#       --prompt-file prompts/electricity_safety_recommended.txt --output result.mp4
#
# 想 A/B 对比时，改文件名即可：
#   --prompt-file prompts/electricity_safety_full.txt
#   --prompt-file prompts/electricity_safety_ultrashort.txt
#
# 文件里以 # 开头的行会被脚本忽略，可放心写注释。
